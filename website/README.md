# OSEN BOOSTVOX RX — Public Website

A standalone public product landing website, kept separate from the private owner admin panel and Android app.

## Deploy
- Create a separate Vercel project from this repository.
- Set the Vercel Root Directory to `website`.
- Framework: Next.js. Build command: `npm run build`.
- No Supabase credentials or private admin secrets are required for this public site.

The current page is a public product introduction. Official downloads and availability are intentionally marked as coming soon until release links are provided.
